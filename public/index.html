Original API playground created by Mark Winteringham, self-hosted here as the target system for my automated test suite.

This is a self-hosted instance of Restful-booker, a Create Read Update Delete Web API with authentication features, used here as an isolated target for my API test automation framework. Running my own instance means no shared state or data collisions with other users testing the public playground.

Deployed via Render, forked from mwinteringham/restful-booker
